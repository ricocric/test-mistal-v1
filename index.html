Aide rapide

Push/Pull : cliquez une face d’un objet (dessus ou côté) et glissez pour l’étirer
Cube / Cylindre / Sphère : clic pour poser
Sélection : clic sur un objet pour le sélectionner, glisser pour le déplacer, Suppr pour supprimer
Caméra : clic-glisser dans le vide = rotation, molette = zoom, clic droit = déplacement latéral
Ctrl+Z : annuler
Prêt. Choisissez un outil.
