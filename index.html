Aide rapide

Push/Pull : cliquez une face, déplacez, puis re-cliquez pour la poser (clic droit / Échap = annuler)
Cube / Cylindre / Sphère : clic pour poser
Sélection : clic sur un objet pour le sélectionner, glisser pour le déplacer, Suppr pour supprimer
Caméra : clic-glisser dans le vide = rotation, molette ou boutons 🔍 = zoom, clic droit = déplacement latéral
Cadrer : touche F ou 🎯 pour ajuster la vue sur la sélection (ou toute la scène)
Mesurer : mode 📏 (touche M), cliquez 2 points pour créer une cote ; les points accrochent les sommets des objets (marqueur vert) ; unité mm/cm/m/km dans la barre ; Fichier > Effacer les cotes
Cote en continu : pendant un Push/Pull, la dimension affichée suit la face en direct ; clic droit > 📐 Dimension précise… pour saisir des valeurs exactes (L l H, ou diamètre/hauteur)
Ctrl+Z : annuler
Fichier : ouvrir/enregistrer un projet (json), importer un objet (obj/stl), fermer le projet, quitter l’application
Clic droit sur un objet : Dupliquer…, Rotation… (angle + axe X/Y/Z), Supprimer, Cadrer ; Ctrl+D duplique la sélection
Déplacement : glissez librement (vitesse écran) ; touches X (axe rouge), Z (axe bleu) et Y (axe vert, vertical) pendant le déplacement pour verrouiller un axe — direction locale à l'objet, donc correcte après rotation — même touche pour libérer
Prêt. Choisissez un outil.
